# Домашняя работа по конфигурационному управлению

Вариант № 5.

## Описание

Программа на Python преобразует текст учебного конфигурационного
языка в YAML.

Для синтаксического анализа используется библиотека Lark.
Для формирования YAML используется библиотека PyYAML.

Входной текст читается из стандартного ввода (stdin).
Результат сохраняется в файл, указанный пользователем.

## Поддерживаемые конструкции

- Многострочные комментарии: #| ... |#
- Числа в научной записи: 1.5e+3, -2e-1
- Имена: латинские буквы [a-zA-Z]+
- Словари: @{ имя = значение; }
- Вложенные словари
- Объявление констант: global имя = значение;
- Использование констант: ^[имя]

Константы вычисляются во время трансляции и не включаются
в итоговый YAML-документ.

При ошибках программа сообщает об ошибке и завершается
с ненулевым кодом.

## Структура проекта

- src/configlang/grammar.lark — грамматика языка Lark
- src/configlang/parser.py — синтаксический анализатор
- src/configlang/evaluator.py — вычисление значений
- src/configlang/yaml_writer.py — создание YAML
- src/configlang/main.py — интерфейс командной строки
- tests/ — автоматические тесты
- examples/ — примеры конфигураций
- run.sh — скрипт запуска программы

## Основные функции

### parser.py

- parse_source(source) — разбирает входной текст и возвращает
  дерево синтаксического анализа.

### evaluator.py

- evaluate_number(node) — преобразует число в float.
- evaluate_reference(node, constants) — подставляет константу.
- evaluate_dictionary(node, constants) — обрабатывает словарь.
- evaluate_value(node, constants) — вычисляет одно значение.
- evaluate_tree(tree) — обрабатывает объявления и конфигурацию.

### yaml_writer.py

- write_yaml(data, output) — сохраняет данные в YAML-файл.

### main.py

- parse_arguments(arguments) — обрабатывает аргументы.
- translate(source, output) — выполняет преобразование.
- main(arguments) — читает stdin и управляет программой.

## Установка

Необходим Python 3.10 или новее.

Создать виртуальное окружение:

    python3 -m venv .venv

Активировать его:

    source .venv/bin/activate

Установить зависимости:

    python -m pip install -r requirements-dev.txt

## Запуск программы

Синтаксис:

    ./run.sh --output OUTPUT

Параметр --output обязателен и задаёт путь к YAML-файлу.

Входные данные передаются через стандартный ввод.

Пример:

    ./run.sh --output output/network.yaml < examples/network.cfg

Просмотр результата:

    cat output/network.yaml

## Примеры использования

### Сетевое оборудование

Входной файл: examples/network.cfg

Команда:

    ./run.sh --output output/network.yaml < examples/network.cfg

Пример демонстрирует константы, вложенные словари,
научную запись чисел и комментарии.

### Лабораторный эксперимент

Входной файл: examples/laboratory.cfg

Команда:

    ./run.sh --output output/laboratory.yaml < examples/laboratory.cfg

Пример демонстрирует несколько уровней вложенности,
научные измерения и повторное использование констант.

## Тестирование

Запуск всех автоматических тестов:

    PYTHONPATH=src python -m unittest discover -s tests -v

Проверяются синтаксис языка, вложенные конструкции,
константы, ошибки ввода, запись YAML и командная строка.

## Проверка качества кода

Проверка Ruff:

    python -m ruff check src tests --select E,W,N,F,I

Проверка цикломатической сложности:

    python -m radon cc src tests -s -n C

Ограничения проекта:

- Длина функции — не более 40 строк.
- Цикломатическая сложность — не более 10.
- Длина строки Python — не более 80 символов.
- Названия функций и классов соответствуют PEP 8.
